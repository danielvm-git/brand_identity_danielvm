# brand_identity_danielvm

Brand identity, design tokens, and static preview for **danielvm.net / Daniel Builds**. This repo is the single source of truth for the personal brand's visual language.

## Quickstart

```bash
git clone https://github.com/danielvm-git/brand_identity_danielvm.git
cd brand_identity_danielvm
./scripts/workflow-setup.sh   # install tooling and sync workspace
```

## Contents

- `brand/tokens.css` — design tokens (color, type, spacing)
- `assets/` — brand assets
- `presets/` — output presets
- `DOCS/` — brand guidelines and documentation
